[ 자바 실행순서 ]
    1. src폴더내 .java 확장자 파일 에서 java 코드 작성
    2. 빌드(build) : run java 실행 
    3. [컴파일] bin폴더내 .class 확장자 파일 (자동)생성
[ 주석 ]
    1. // 한줄석 
    2. /* */ 여러줄주석

[ 용어 ]
    1. package : 해당 클래스가 위치한 폴더명
    2. class : 자바에서 *컴파일* 하는 최소의 단위 *클래스 { } 안에서 코드작성*
    3. main함수 : 자바에서 *코드 실행*하는 흐름 = 스레드 제공 
    4. ;세미콜론 : 코드의 한문장 마침 뜻 

[ 자료 ] : 데이터
    1. 리터럴 : 상수( true/false , 'a' , 3 )
    2. (기본)자료타입(형)
        1) boolean  1byte   true/false 
        2) char     2byte   ''감싼 문자1개저장 
        3) byte     1byte   -128 ~ +127
        4) short    2byte   -+3만정도 
        5) int      4byte   -+21억정도      * 정수 리터럴 기본타입 *
        6) long     8byte   -+21억이상 , L/l
        7) float    4byte   소수점8자리표현 , F/f
        8) double   8byte   소수점17자리표현    * 실수 리터럴 기본타입 *
        *) String   N*2byte ""감싼 문자N개저장, 문자열객체(배열)

[ 출력함수 ]
    1. System.out.print( )  : 출력 
    2. System.out.println( ) : 출력+줄바꿈 
    3. System.out.printf( "형식문자" , 자료 ) : 형식문자
    *) 이스케이프/제어 문자 : \n \t \' \" \\
    *) 형식문자 : %s문자열 %d정수 %c문자 %f실수 , %자릿수s %-자릿수s %0자릿수s %전체자릿수.수소점자릿수f  

[ 입력함수 ]
    1) 입력객체 생성( 클래스 마다 1개만 선언 )
        Scanner 변수명 = new Scanner( System.in );
    2) 입력객체 통한 입력함수( nextXXX() , 타입 주의 , 여러개 next() 엔터기준으로 구분 )
        타입 변수명 = 변수명.nextXXX();
    *) .nextLine() : 개행(\n) 사용하기 때문에 앞에 다른 .nextXXX() 존재 했을때 앞전 개행 포함
    예] .nextInt() ~ .nextLine() : nextInt() 에서 3 입력 후 엔터(개행\n) 치면 3반환되고 엔터(개행\n) 남는다.
    해결방안 : .nextLine() 사이에 하나 추가한다.
    .next() 문자열(띄어쓰기x) [vs] .nextLine() 문자열(띄어쓰기o)

[ 타변변환 ]
    * 다형성 : (하나의 자료/값) 다양한 형태(타입) 갖는 성질
    1) 자동타입변환 : byte -> short -> int -> long -> float -> double , * 연산 결과 *
    2) 강제타입변환 : double -> float -> long -> int -> short -> byte , (변환할타입명)자료

[ 연산자 ]
    1. 산술연산자: + - * / %
    2. 연결연산자: +
    3. 비교연산자: > < >= <= == !=
    4. 논리연산자: && || !
    5. 증감연산자: ++변수명 , 변수명++ , --변수명 , 변수명--
    6. 대입연산자: =  , 복합대입연산자: +=  -=  *=  /=  %=
    7. 삼항연산자: 조건 ? 참 : 거짓  , 중첩:  조건1 ? 참1 : 조건2 ? 참2 : 거짓  -> 참/거짓 
    * 문자열비교함수: 문자열A.equals( 문자열B )
